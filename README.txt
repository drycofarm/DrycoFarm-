DryCo Farm Website

This version includes the four product detail pages and a Quick Order on WhatsApp form.

Product order form fields:
- Name
- Quantity
- Size: 100 g, 200 g, 500 g
- Delivery Address

The Order on WhatsApp button opens a pre-filled WhatsApp chat to DryCo Farm's main number +91 99691 29992.

Important: a static website/wa.me link cannot automatically post a customer's message into a WhatsApp group while simultaneously making the customer chat appear as the business's private number. The supplied group invite is therefore not exposed to customers. To relay orders into the group automatically, a server-side WhatsApp automation/business integration would be required.
